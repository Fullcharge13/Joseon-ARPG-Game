# v0.2 설계 — 실제 휴대폰으로 재미 확인

작성 2026-11-06. 사용자 승인: "진행, 공개 허락".

## 목적
v0.1의 수치(층 길이, 창귀 세기)는 봇 기준이다. 사람이 실제 휴대폰으로 해 본 기록을 받아 봇과 나란히 비교할 수 있게 한다. 이번 판은 **수치를 바꾸지 않는다**.

## 1. 웹 공개
- `.github/workflows/pages.yml`: `main`에 올라가면 `dist/`를 GitHub Pages로 배포한다.
- 주소: `https://fullcharge13.github.io/Joseon-ARPG-Game/`
- 저장소 Pages 설정은 "GitHub Actions" 방식으로 켠다(사용자 허락 받음, 실제 켜기는 푸시 때).

## 2. 홈 화면 앱
- `dist/manifest.webmanifest`: 이름 「백귀사」, 가로 화면, 전체 화면(`fullscreen`, 아이폰은 이를 무시하고 앱 화면으로 엶), 배경 #120c10, 아이콘 192·512.
- `dist/sw.js`: 게임 파일은 **네트워크 먼저, 끊기면 저장본**(조선퇴마록과 같은 방식). 캐시 이름은 `baekgwisa-<판>`이고 빌드가 맞춘다. 판이 바뀌면 옛 캐시를 지운다.
- 등록은 https 또는 localhost일 때만(파일로 열면 건너뜀).
- 아이콘: 선비 도트(코드)를 `build.py`가 PNG로 만든다(외부 그림 없음).

## 3. 내 플레이 기록
- 저장 판 `saveVer` 1 → **2**: 캐릭터에 `stats`(최근 30층) 추가. 옛 저장은 빈 기록으로 옮긴다.
- 한 층이 끝날 때(다음 층, 보스 처치, 쓰러짐, 마을로 귀환) 한 줄 기록. 층 중간에 앱이 꺼지면 다음에 켤 때 「중단」으로 기록(화면이 가려질 때 진행 중 층을 저장해 둠, 검토 반영):
  `{v, at, dev('휴대폰'|'PC'), tier, floor, sec, end('clear'|'won'|'dead'|'home'|'quit'), lvl, kills, taken, by(받은 피해 출처 상위 3), bossSec}`
- 퇴마청 「기록」 창: 최근 기록 표 + 업 1단계 층별 평균 시간.
- 「기록 복사」: 요약 글을 클립보드로. 안 되면 글 상자를 띄워 직접 고르게 한다.

## 4. 시험
- 단위: 층 끝마다 기록 한 줄, 30개 넘으면 오래된 것부터 버림, v1 저장 → v2 옮기기, 요약 글에 층 시간·쓰러짐·받은 피해 출처가 들어감.
- 브라우저(로컬 http 서버로): 기록 창 열기·복사, 앱 정보 파일 읽힘, 오프라인 저장 등록됨, 아이콘 파일 있음.

## 하지 않는 것
수치 조정, 새 내용(직업·스킬·던전).

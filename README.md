# 조선퇴마록 외전: 백귀사 (v0.1)

> 이 파일은 `node tools/readme_gen.js` 가 게임 데이터에서 만듭니다. 표를 손으로 고치지 말고 `src/js/02_data.js` 를 고친 뒤 다시 만드세요.

조선퇴마록 세계관을 잇는 **작은 정통 도트 ARPG**입니다. 선비가 요괴가 들끓는 폐사찰 「백귀사(百鬼寺, 가상의 절)」를 내려가며 장비를 줍고, 스킬 갈래와 전설 효과로 빌드를 맞춥니다.

- 웹 브라우저 하나로 PC와 휴대폰(가로 화면)에서 플레이합니다. 파일은 `dist/index.html` 한 장입니다.
- 외부 라이브러리·이미지 파일 없이, 그림은 모두 코드로 그리고 소리는 Web Audio로 합성합니다.

## 조작
| | PC | 휴대폰 |
|---|---|---|
| 이동 | WASD·방향키 | 왼쪽 아무 곳이나 눌러 생기는 조이스틱 |
| 스킬 | 좌클릭·우클릭·1~4 (마우스 쪽으로 조준) | 오른쪽 아래 버튼 4개 (가까운 요괴 자동 조준) |
| 회피 | Space | 「회피」 버튼 |
| 메뉴 | Esc 멈춤 · I 가방 · K 수련 | 오른쪽 위 ≡ |

## 한 판의 흐름
1. **퇴마청**(마을)에서 장비를 고르고 수련점을 찍은 뒤 출정합니다.
2. 백귀사는 3층입니다. 층마다 방 9·10·11개를 손으로 짠 방 조각 8종으로 무작위로 이어 붙입니다. 계단에 서면 다음 층으로 가고, 층마다 자동 저장합니다.
3. 3층 끝 방의 **대장 도깨비**를 물리치면 **업(業) 단계**가 하나 열립니다. 단계마다 요괴 레벨 +4, 좋은 장비가 더 자주 나옵니다.
4. 쓰러지면 마을로 돌아가고 엽전 10%만 잃습니다. 장비·레벨은 그대로입니다.
5. 요괴가 가끔 떨어뜨리는 **복숭아**를 주우면 체력 22%를 회복합니다(정예는 반드시).

## 스킬 (레벨마다 수련점 1 · 3단계에서 갈래 · 최대 5단계 · 마을에서 무료 재배분)
| 스킬 | 피해 종류 | 기력 | 재사용 | 계수 | 설명 | 갈래 ① | 갈래 ② |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 먹탄 | 일반 | +6 | 0.4초 | ×1 | 먹 덩어리를 날린다. 기력을 쓰지 않고 오히려 6 채운다. | 「번지는 먹」 맞은 자리에서 작게 터진다(반경 22, 피해 50%). | 「꿰뚫는 먹」 요괴 2마리를 더 꿰뚫는다. |
| 화염부 | 불 | 18 | 0.9초 | ×1.6 | 불 부적을 던져 터뜨린다. 맞은 요괴는 3초 동안 불탄다. | 「큰 불」 폭발 반경 +50%. | 「연발」 작은 부적 2장을 더 던진다(각 피해 50%). |
| 일필휘지 | 일반 | 28 | 2.5초 | ×3.2 | 조준한 방향으로 붓을 한 획 그어 그 위의 요괴를 모두 벤다. | 「긴 획」 획 길이 +60%. | 「먹물 웅덩이」 획 자리에 2초 동안 먹물이 남아 요괴를 느리게 하고 피해(30%)를 준다. |
| 한설 | 냉기 | 32 | 5초 | ×2 | 둘레에 찬 서리를 터뜨려 요괴를 느리게 한다. | 「얼음 감옥」 맞은 요괴를 1.2초 동안 묶고(보스는 묶이지 않음), 그동안 받는 피해 +20%. | 「찬 바람」 반경 +40%, 피해 +25%. |
| 결계 | 일반 | 25 | 10초 | ×0.3 | 5초 동안 최대 체력의 30%만큼 피해를 막는 결계를 친다. | 「두꺼운 결계」 막는 양 +60%. | 「맑은 기운」 결계가 있는 동안 기력 회복 2배. |

## 장비
부위 4개: 붓 · 갓 · 도포 · 노리개. 등급: 일반 · 마법 · 희귀 · 전설(옵션 0 / 1~2 / 3~4 / 2~3 + 전설 효과).
대장간에서 엽전을 내고 옵션 하나를 다른 옵션으로 다시 굴릴 수 있습니다(같은 장비는 굴릴수록 비싸짐).

보스 **대장 도깨비** — 도깨비들의 우두머리. 방망이로 땅을 내려찍고 돌진한다. 큰 공격 전에는 바닥에 붉은 범위를 0.8초 먼저 보여 줍니다. 체력 절반 아래에서 분노해 더 자주 공격합니다.

| --- | --- |

| 불타는 | 닿거나 곁에 있으면 불탄다(초당 최대 체력 2%) |

## 만들기와 시험
```
python3 build.py                      # src/ → dist/index.html
bash tests/run_all.sh                 # 단위 시험 + 자동 플레이 12판 + 브라우저 화면 순회
node tests/sim/play.js 12 3           # 자동 플레이만(판 수, 보스 처치 목표)
node tools/readme_gen.js              # 이 README 다시 만들기
```
- `tests/unit/`: 규칙·저장·던전·전투 시험(전설 효과·갈래·옵션이 모두 실제 전투 결과를 바꾸는지 포함)
- `tests/sim/play.js`: 봇이 마을 ↔ 던전을 오가며 업 단계를 올리는 자동 플레이
- `tests/browser/flow.py`: 실제 브라우저(PC·휴대폰 2종)로 화면 순회, 넘침·콘솔 오류·프레임 시간
- 설계: `docs/specs/`, 계획: `docs/plans/`, 개발 일지: `LOG.md`

## 출처와 저작권

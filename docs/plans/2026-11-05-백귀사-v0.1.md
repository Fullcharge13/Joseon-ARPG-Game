# 백귀사 v0.1 구현 계획

- **목표**: 설계 문서의 MVP를 `dist/index.html` 한 장으로 만든다.
- **구조**: 규칙(03~05)은 DOM 없이 Node 시험, 세계(06~07)는 가짜 화면 하네스로 자동 플레이, 화면(08~12)은 Playwright로 확인.
- **도구**: 순수 JS, canvas 2D, Web Audio, Python `build.py`, Node `node:test`, Playwright.
- **설계**: `docs/specs/2026-11-05-조선-요괴-ARPG-설계.md`
- **전역 제약**: 외부 라이브러리 없음, 배포물 한 장, `GAME_VER='v0.1'`, 저장 키 `baekgwisa-save`, `saveVer=1`.
- **검토 초점**: ① 방 이어 붙이기에서 막힌 길 ② 효과 없는 옵션·전설 ③ 창이 열린 직후 잘못 누름 ④ 깨진 저장으로 시작 불가 ⑤ 휴대폰에서 버튼이 화면 밖으로 넘침.

## 작업 1. 하네스와 규칙 (03_rules, 02_data)
- 파일: `tests/harness.js`, `tests/unit/rules.test.js`, `src/js/00_util.js`, `02_data.js`, `03_rules.js`
- 시험: `xpNeed(1)=30`, `xpNeed(2)=90`; `armorReduce(0,1)=0`, 상한 0.75; 옵션마다 `calcStats` 결과가 바뀜; 전설마다 해당 스킬 피해가 바뀜; `rollItem` 등급별 옵션 개수 범위; `reroll`이 같은 옵션 중복 없음; 수련점 합 = 레벨−1, 재배분 후 모두 돌려받음.
- 확인: `node --test tests/unit`

## 작업 2. 저장 (05_save)
- 시험: 빈 저장 → 새 캐릭터, 깨진 글자 → 새 캐릭터 + 백업 보존, `saveVer` 0(필드 누락) → 1로 옮김, 저장→불러오기 왕복 같음.

## 작업 3. 던전 (04_dungeon)
- 시험: 시드 1~500 × 층 1~3에서 시작 방 → 계단(또는 보스 방) 경로 존재, 모든 바닥 칸 도달 가능, 방 조각 문 위치가 가장자리 가운데.

## 작업 4. 세계와 스킬 (06, 07)
- 시험: 자동 조준 대상이 살아 있고 사거리 안이면 유지; 보스 큰 공격은 예고 0.8초 전에는 피해 0; `hurt` 출처 기록; 정예 접두어 적용.

## 작업 5. 화면 (01, 08~12, shell)
- 확인: 빌드 후 브라우저 순회.

## 작업 6. 시뮬레이션·조정
- `node tests/sim/play.js 12` → 층 시간·보스 시간·레벨·피해 비중 표.

## 작업 7. 문서
- `tools/readme_gen.js`로 README 표 생성, LOG.md v0.1.

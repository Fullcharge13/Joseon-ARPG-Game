# 조선퇴마록 외전: 백귀사 — 설계 (v0.1 MVP)

작성 2026-11-05. 사용자가 대화에서 고른 결정과, "추천 방향으로 MVP까지 진행" 승인에 따라 채운 추천안을 함께 적는다.

## 1. 한 줄 소개와 성공 기준
- 조선퇴마록 세계관을 잇는 **작은 정통 도트 ARPG**. 선비가 요괴 들끓는 폐사찰 「백귀사(百鬼寺, 가상의 절)」를 내려가며 장비를 줍고 빌드를 맞춘다.
- 성공 기준: PC·휴대폰 브라우저에서 **10분 동안 장비 줍고 갈아 끼우며 싸우는 것이 재미있는가**를 사용자가 직접 확인할 수 있는 판.

## 2. 사용자가 고른 결정
| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹 무료 공개, 휴대폰(가로 화면)과 PC |
| 조작 | 휴대폰: 떠다니는 조이스틱 + 스킬 버튼 4 + 회피 1 + 자동 조준 / PC: WASD + 마우스 조준 + 1~4 + 스페이스 |
| 진행 | 디아블로식 영구 캐릭터, 마을 ↔ 던전, 층마다 자동 저장 |
| 장비 | 등급(일반·마법·희귀·전설) + 무작위 옵션 + 스킬을 바꾸는 전설 효과, 대장간 옵션 재굴림 |
| 직업 | 선비 |
| 스킬 | 작은 스킬 트리: 레벨마다 수련점 1, 4개 장착, 3단계에서 갈래 선택, 마을에서 무료 재배분 |
| 던전 | 손으로 짠 방 조각을 무작위로 이어 붙임 |
| 구조 | 새 저장소, 조선퇴마록에서는 도트 틀(mk, 선비 조립, 요괴 틀)과 요괴 도감 이름만 복사 |

## 3. 추천안으로 채운 부분 (MVP 범위)
- **마을 「퇴마청」은 메뉴 화면**(걸어 다니는 마을은 다음 판). 버튼: 출정, 가방, 수련, 대장간.
- **던전**: 백귀사 3층. 층마다 방 6~8개, 마지막 방에 계단. 3층 끝 방은 보스 방. 보스를 잡으면 **업(業) 단계**가 하나 올라 다음 출정의 요괴 레벨 +4, 좋은 장비 확률이 오른다(작은 엔드게임).
- **스킬 5개**(먹탄·화염부·일필휘지·한설·결계) + 회피. 4칸에 장착.
- **장비 4부위**: 붓(무기)·갓·도포·노리개. 옵션 11종, 전설 효과 5종(스킬마다 하나).
- **피해 종류 3가지**: 일반, 불(화상: 3초간 초당 20%), 냉기(둔화 40%, 2초).
- **요괴 5종**(한국 요괴 도감 이름): 귀화·꺼먹살이·도깨비·창귀·백여우. 정예 접두어 3종: 날랜·단단한·불타는. 보스: 대장 도깨비(내려찍기·돌진·도깨비불 부르기, 체력 50% 아래에서 빨라짐). 보스 큰 공격은 **0.8초 전 붉은 범위 예고**.
- **죽으면** 마을로, 엽전 10% 잃음. 가방의 장비는 잃지 않는다.
- **줍기**: 가까이 가면 자동으로 줍는다(휴대폰 배려). 가방 30칸, 꽉 차면 바닥에 남는다.

## 4. 구조
- `src/shell.html` + `src/js/*.js`를 `build.py`가 `dist/index.html` 한 장으로 합친다. 외부 라이브러리 없음, canvas 2D, Web Audio 합성음.
- 규칙(계산)과 화면을 나눈다. 규칙 파일은 DOM 없이 Node에서 시험한다.

| 파일 | 맡는 일 |
|---|---|
| 00_util | 시드 난수, 수학 도움 함수 |
| 01_sprites | 코드 도트(선비, 요괴, 바닥·벽 타일, 아이콘), 테두리 |
| 02_data | `SKILLS`, `AFFIXES`, `LEGENDS`, `SLOTS`, `ENEMIES`, `ELITE_MODS`, `ROOMS`, `GAME_VER` |
| 03_rules | 능력치 합산, 피해 계산, 경험치 곡선, 요괴 레벨 성장, 장비 생성, 재굴림, 수련점 |
| 04_dungeon | 방 배치(무작위 걷기) → 방 조각 이어 붙이기 → 타일 지도, 충돌 |
| 05_save | 저장·불러오기·옛 저장 옮기기(`saveVer`), 깨진 저장 보호 |
| 06_world | `update(dt)`: 플레이어·요괴 인공지능·투사체·`hurt`·드롭·층 이동·보스 |
| 07_skills | 스킬 시전(표의 함수) |
| 08_input | 키보드·마우스·터치(조이스틱, 버튼) |
| 09_render | 세계와 HUD 그리기 |
| 10_ui | 마을·가방·수련·대장간·멈춤·쓰러짐 창(DOM) + 입력 보호 0.4초 |
| 11_audio | 합성음 |
| 12_boot | 시작과 반복 |

## 5. 핵심 공식(시작값, 시뮬레이션으로 조정)
- 필요 경험치: `round((5 + 9(L−1) + (L−1)^2.2) × 6)`, 최대 레벨 30.
- 요괴 레벨 `ml = 층 + 4×(업 단계−1)`, 체력 배수 `1.13^(ml−1)`, 피해 배수 `1.09^(ml−1)`.
- 장비 레벨 = 요괴 레벨. 붓 기본 공력 `6 × 1.12^(il−1)`, 옵션 값은 `기본 × (1 + 0.08(il−1))`.
- 피해 = 스킬 계수 × 공력 × (1 + 피해% + 종류%) × 단계 배수(`1 + 0.25(단계−1)`) × 치명.
- 방어 경감 = 방어 / (방어 + 40 + 12 × 요괴 레벨), 최대 75%.
- 보스 1초 피해 상한: 최대 체력의 8%.

## 6. 목표 지표 (자동 플레이 12판 중앙값)
- 한 층 3~6분, 보스 25~70초, 첫 보스 처치 때 레벨 7~11, 장비 착용 중 희귀 이상 1개 이상.
- 한 스킬의 피해 비중 60% 이하(스킬이 5개뿐이라 30%는 MVP에 맞지 않아 넓게 잡음).
- 효과 없는 옵션·전설 효과 0개(자동 검사).

## 7. 시험
- 단위: 피해·방어·경험치, 옵션마다 능력치 변화, 전설 효과마다 피해 변화, 방 이어 붙이기 500 시드 연결성, 저장 옮기기·깨진 저장, 수련점·재배분, 재굴림, 자동 조준 고정, 보스 예고 전 피해 없음.
- 자동 플레이 12판(`tests/sim/play.js`).
- 실제 브라우저(`tests/browser/flow.py`): PC 1280×720, 휴대폰 844×390(터치), 화면 순회·콘솔 오류·넘침·캡처, CPU 4배 감속 프레임.

## 8. 고증·저작권
- 요괴 이름과 설명은 조선퇴마록과 같이 고성배 「한국 요괴 도감」 기반. 백귀사는 가상의 절이며 특정 종교 시설을 본뜨지 않는다.
- 모든 그림은 코드로 새로 그린다.

## 9. 다음 판으로 미룬 것
걸어 다니는 마을, 직업 추가, 스킬 8개 이상, 끌어서 조준, 저항 옵션, 상점 구매, 홈 화면 앱(sw.js), 다국어.

## 10. 구현 중 바뀐 것 (시험·시뮬레이션이 찾은 문제)
| 바뀐 것 | 까닭 |
|---|---|
| 옵션 11종 → **16종**(스킬 단계 +1 옵션 5종 포함), 도포에도 기력 회복·재사용 대기 옵션 | 도포 옵션이 4종뿐이라 옵션 4개짜리 희귀 도포는 대장간 재굴림이 불가능했다(시험이 찾음) |
| 「얼음 감옥」: 묶는 동안 **받는 피해 +20%** 추가(보스는 묶이지 않고 피해만) | 묶기만 하면 보스에게 효과가 없었다(탐침 시험이 찾음) |
| 「불타는」 정예: 곁에 있으면 불탐(초당 최대 체력 2%) | 「지나간 자리에 불」은 MVP에서 빼고 단순하게 |
| 시선 검사를 칸 단위로 정확하게, 먹탄은 같은 선 위에서 발사, 투사체는 지나온 선분 전체로 맞음 판정 | 자동 조준이 「보인다」는 대상을 먹탄이 기둥 모서리에서 놓쳤다(300번 중 8번) |
| 요괴 **길 안내 지도**(0.4초마다 플레이어 칸에서 거리 퍼뜨림) | 요괴가 기둥·연못 뒤에 걸려 서 있었다 |
| 보스 돌진 예고선을 벽에서 자름 | 예고가 실제 돌진 거리보다 길었다(캡처에서 찾음) |
| **복숭아**(주우면 체력 22%, 정예는 반드시) | 회복 수단이 없어 층을 내려갈수록 체력이 깎인 채 쌓였다 |
| 층마다 방 6·7·8 → **9·10·11**, 2층부터 무리 하나 더, 요괴 체력 ×1.25, 경험치 ×5.5, 보스 체력 1500 → 1200 | 층이 너무 짧고 보스전이 길었다(시뮬레이션) |
| 업 1단계 1층은 **익히는 층**: 정예는 계단 방에만, 시작 방 옆 방은 무리 1개 | 레벨 1 선비가 첫 층에서 정예에게 수 초 만에 쓰러졌다 |
| 아이콘에 밝은 테두리 | 먹탄·갓 아이콘이 어두운 버튼에 묻혔다(캡처) |
